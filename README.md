**# Counter Project**

## Overview
Counter Project is a simple React application that demonstrates the use of state management and hooks to create a counter functionality. Users can increment, decrement, and reset the counter value.

## Live Demo
You can view the live demo of the application at the following link: [Counter Project 1 - Live Demo](https://counter-project-1-react.vercel.app/)

## Features
- Increment the counter
- Decrement the counter
- Reset the counter to zero
- Responsive design

## Technologies Used
- React
- Vite
- ESLint
- JavaScript (ES6+)

## Installation
To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/counter-project-1-react.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd counter-project-1-react
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser and visit**
   ```
   http://localhost:3000
   ```

## Usage
- Click the "+" button to increment the counter.
- Click the "-" button to decrement the counter.
- Click the "Reset" button to reset the counter to zero.
